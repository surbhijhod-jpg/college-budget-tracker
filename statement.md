# College Budget Tracker - Project Statement

## 1. Problem Statement

College students spend money on different things such as food, travel, books, and other daily needs. It can be difficult to keep track of all these expenses.

The College Budget Tracker is made to help students keep a simple record of their expenses and understand how much money they are spending.

## 2. Scope of the Project

The project is designed for basic personal budget tracking.

It allows the user to:

- Set a monthly budget
- Add expenses
- View expenses
- Calculate total spending
- Check remaining budget
- Find the highest expense
- Calculate average expense
- Search for an expense by category
- Check whether they can afford something
- View a monthly report

The project is a simple Python-based application and does not use an online database or external services.

## 3. Target Users

The main users of this project are:

- College students
- Students who want to track their daily expenses
- Students who want to manage their monthly budget

## 4. High-Level Features

The main features of the College Budget Tracker are:

1. Monthly budget setting
2. Adding expenses
3. Viewing expenses
4. Calculating total expenses
5. Checking remaining budget
6. Finding the highest expense
7. Calculating average expense
8. Searching expenses by category
9. Checking if an item can be afforded
10. Generating a monthly report
